⚠
HTTPS is required for phone GPS/motion access in this browser.

Modern Android Chrome restricts navigator.geolocation and DeviceMotionEvent to Secure Contexts. Ordinary HTTP over a local IP (e.g., http://192.168.x.x:5500) is considered insecure by modern browsers.

How to enable sensor access on Android Chrome
  1. Option A (Recommended - USB Port Forwarding): Connect your phone via USB, open chrome://inspect/#devices on your laptop, and forward port 5500 and 8000. Then open http://localhost:5500/sensor.html on the phone (Chrome treats localhost as a secure context).
  2. Option B (Chrome Insecure Origin Flag): On your phone's Chrome browser, navigate to chrome://flags/#unsafely-treat-insecure-origin-as-treat-secure, add your laptop's URL (e.g., http://<LAPTOP_IP>:5500), enable the flag, and restart Chrome.
  3. Option C (Local HTTPS): Serve the frontend using an HTTPS local server (e.g., via mkcert or a self-signed certificate).
