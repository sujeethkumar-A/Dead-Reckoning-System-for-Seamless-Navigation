    Recovery options A new valid GPS fix automatically re-anchors navigation. If the position estimate is unavailable, reconnect the phone's GPS; the displayed last fix is reference-only.

    Other project features Demo Mode is isolated simulated data for demonstrating flows, not a real-position fallback. The ML model is not applied to real-time navigation. Accelerometer and gyroscope readings are telemetry only and are not treated as speed or heading.

    Diagnostics export stays in your browser download and can include precise location and sensor readings. Review it before sharing.
